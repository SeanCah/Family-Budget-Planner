# Family-Budget-Planner

A full-stack family budgeting and financial planning application.

## Goal

Help families manage their finances from one easy-to-use dashboard.

## Features

- Expense Tracking
- Income Tracking
- Monthly Budget
- Recurring Bills
- Credit Card Manager
- Savings Goals
- Net Worth Dashboard
- Calendar
- Reports
